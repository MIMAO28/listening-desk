# 听写练习台

个人使用的英语、日语精听工具：导入文字或 TXT、自动断句、逐句朗读、全文连播、听写、中文查词、专注模式和深夜模式。

这是 GitHub Pages 的静态发布文件仓库。练习内容仅保留在使用者当前页面内，刷新后重新开始。

朗读使用浏览器提供的系统声音，不需要付费语音接口。声音是否可用取决于设备及浏览器。

角色使用 [Yippee](https://rive.app/marketplace/27915-52755-yippee/)，作者 [gianluigi.ranauro](https://rive.app/@gianluigi.ranauro)，采用 CC BY 4.0；使用原动画并裁取耳机角色区域，添加网页交互。详细署名见 characters/yippee/CREDITS.txt。

英汉词库来源为 [ECDICT](https://github.com/skywind3000/ECDICT)，MIT 许可，详情见 dictionaries/ECDICT-LICENSE.txt。Rive Canvas 运行库的 MIT 许可见 vendor/rive/LICENSE。
