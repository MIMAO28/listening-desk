# 主题配色

顶部“配色”按钮收录 Happy Hues 当前公开的17套方案（01–17）。色卡保留官网的基础颜色及编号，中文名称是本站为方便辨认添加的别名；每套都能打开对应官网来源。基础色值存于 src/lib/happyHues.json，由 scripts/import-happy-hues.mjs 从官网下载的研究副本提取，不复制官网页面代码或插画。

配色与日间/深夜是独立选择。官网原有明暗倾向不同，本站为听写界面派生表面、正文、辅助文字、边框、链接、焦点及提示色，确保正文和按钮文字的对比度至少4.5:1。官网原始按钮色和色卡仍保留；派生夜间界面并不声称是Happy Hues另行提供的原版方案。

首页、练习、查词和弹窗共享颜色。Yippee原始动画文件不变，通过SVG灰度到主题颜色映射调整画布和启动图片；保留原动作、互动和作者署名。切换主题不重新加载角色、不重启朗读、不清空听写。

主题选择保留在当前页面会话内，与此前无需自动保存的策略一致；刷新会恢复默认17号主题和日间模式，不保存材料或答案。

键盘打开色卡后可用方向键选择、Home/End跳到首尾、Escape关闭；关闭后焦点回到“配色”。手机采用两列色卡，列表单独滚动，完成和关闭入口保持可见。

配色来源：https://www.happyhues.co/ ，作者 Mackenzie Child。
