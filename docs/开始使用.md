# 开始使用听写练习台

## 在线使用

打开 [在线听写练习台](https://mimao28.github.io/listening-desk/) 即可练习，不需要先运行本机脚本或登录账号。当前使用免费 GitHub Pages；用户已确认手机5G可打开。旧 chatgpt.site 域名已出现手机网络安全拦截，不再作为主要分享地址。

首页采用白底、紫字与粉色按钮，搭配原版 Yippee 耳机角色。语言分区在首屏下方，向下滚动或点击“选择语言，开始练习”后选择英语、日语卡片；进入训练页再通过“导入材料”粘贴文字或选择 TXT，也可以先试听示例。

当前封面为“让每一次聆听都更接近理解。”，桌面显示为一行。首页展示 gianluigi.ranauro 的 Yippee 原版 Rive 动画（CC BY 4.0），保留原脸部与配色，裁取耳机角色区域，悬停抬起、点击轻摆，支持键盘操作。来源与适配说明位于首页页脚。动画及运行库由本站加载，默认静音，暂停与系统“减少动态效果”控制实际动画播放。

角色首先显示内嵌的约10KB原动画帧，不等待动画引擎下载。引擎、动画文件并行加载，第一帧实际渲染后平滑切换；慢网络、加载失败或超时会保留角色图片，仍可正常进入训练。

右上角可切换日间与深夜模式，模式同时改变首页、训练区、输入框与导入窗口。每次进入默认日间。首页的角色动画可以暂停，也会自动尊重系统的“减少动态效果”设置。

英语恢复多个可选声音，保留浏览器实际提供的在线及本地音色，美式自然音色优先排序（例如 Andrew、Aria、Guy、Jenny）。声音列表会在在线音色到达后刷新；手动选定后不会被自动换回系统声。点击“试听”比较同一段英文样句；更换音色可连续比较，不改变训练句子、听写内容或三遍开关。主播放按钮始终启动原文练习。

没有新增付费语音服务，也不需要阿里云账号。各浏览器提供的声音不同：独立测试窗口仅有基础系统声，不代表用户日常 Edge 没有在线音色。系统声不标成自然音色或官方托福原声；在线音色可能需要网络缓冲，原本仅针对本地引擎的卡住恢复不会打断在线加载。

练习仅保留在当前页面。刷新、关闭后重新打开，都会从示例和空白听写重新开始；自动保存、备份和恢复已按最新使用偏好取消。切句、换声音和切换专注模式不会清空同一页面内的输入。

## 专注与查词

训练区右上角点击“专注练习”，收起首页与导航。可调整阅读字号、原文与听写栏宽，或直接更换材料；点击“退出专注”或按 Esc 返回。导入窗口打开时，Esc 只关闭导入窗口。

训练旁栏直接显示声音选择和刷新声音，播放器下方常驻显示 Alt+K 播放/暂停、Alt+J 上一句、Alt+L 下一句、Alt+R 重复。训练页的“设置”提供字号、双栏比例和调整断句；Esc 优先关闭已展开的设置，再次按 Esc 退出专注。点击页头的品牌图标返回首页。

训练区旁的“随手查词”可以直接输入单词或短语。也可在听写框中选中一个词，点“选词查词”，在旁栏查看结果。只显示中文词义和中文词性，不再展示英文长解释、例句或音标。多义词可以展开其余词义；词义来源收在可展开的小项中。英汉词库按需加载，日语及未收录词会在线获取中文译文。网络失败时可打开详细词典继续查询。

## 本地开发时打开

1. 按 **Win + E** 打开 Windows 文件资源管理器。
2. 在文件资源管理器的地址栏输入 `F:\Gpt-Listening-app`，回车。
3. 在文件列表中双击 **启动练习.cmd**，浏览器会打开 `http://127.0.0.1:5173/`。

Codex 聊天中的文件链接会打开源码预览，不能代替运行脚本。不要双击 `index.html` 或 `dist/index.html` 进入练习；地址栏应显示 `http://127.0.0.1:5173/`。

保留启动窗口；关闭窗口会停止本次服务。下次练习再双击即可。只监听本机地址。

也可以在项目目录的 PowerShell 中运行：

```powershell
npm.cmd run dev
```

然后在浏览器手动打开上述地址。每次打开都是一次新的练习。

## 第一次练习

1. 在“朗读声音”里确认选择了英语声音。先用三句原创示例，试听声音效果。
2. 点击播放，中途暂停、继续；再试上一句、下一句和重复三次。
3. 在右侧写下听到的内容。需要时隐藏原文、只查看当前句。
4. 点击“导入材料”，粘贴自己的文字或选择 UTF-8 TXT，自动断句后检查预览；每行对应一句，可以直接修改。
5. 需要查词时使用旁栏，想集中练习时开启专注模式；刷新页面会重新开始。

语音试用版通过浏览器直接朗读，目前没有导出 MP3 的功能。

## Windows 没有英语声音时

页面会禁用英语朗读并给出提示。点击页面的“打开 Windows 语音设置”，在“管理语音 / 添加语音”中找到并安装英语（美国）的文本转语音声音。安装后重新打开浏览器，点击“刷新声音”。

本轮已按用户选择准备官方语音组件安装脚本 `scripts/install-english-voice.ps1`：通过 Windows 管理员授权，仅添加 `Language.TextToSpeech~~~en-US~0.0.1.0`，不更改显示语言、不主动重启。进度记录在 `output/voice-setup-status.json`。

本轮安装已完成，不需要重启系统。重开的独立 Edge 会话已经列出 Mark、Zira、David 三个本地英语声音，并使用 Mark 通过了真实的启动、暂停、恢复和结束事件验证。如果日常浏览器还没有显示新声音，请先完全退出并重新打开浏览器。

Windows Narrator 的“自然声音”与网页可用的传统声音不同，不保证 Narrator 的声音会出现在网页列表里。声音是否可用以页面声音列表为准。

声音标注“本地”时使用设备声音；手动选择“在线”声音时，文本会交给对应语音服务，需要网络。

## 键盘

顶部“配色”可选择17套Happy Hues主题；日间/深夜按钮单独控制明暗。主页角色、练习和查词界面都会随配色变化，不会中断播放或清空听写。当前会话可在首页、英语和日语之间沿用选择，刷新后重新开始。

点击任意原文句子会立即开始从该句连播，与上下句按钮和快捷键行为一致；即使原先暂停，也会开始播放所选句。开启三遍时，手动选句从第一遍重新计数，三遍结束继续下一句。

点击**播放**即从当前句连续读到材料末尾，高亮自动跟随；独立的全文连播按钮已删除，中途可暂停、继续或停止。

**重复 3 次**现在是开关：先开启，再点播放，每句读三遍后自动进入下一句，直到最后一句读完。再次点击可关闭。上下句快捷键立即中断旧句、播放新句，并从第一遍计数。暂停时切换重复开关会保持安静，点继续后生效；停止后重复开关仍保留本页选择，刷新后重置。

自动进入下一句后，手动跳回任何一句仍会保留三遍模式，并在三遍结束后继续向后播放。

Microsoft 在线声音支持当前页面的音频缓存：点击播放后，先取得当前句音频，再后台准备相邻句。三次重复、返回已缓存的句子和更改语速不需要重新合成。第一次使用新句或新声音仍需联网，页面会提示“正在准备这句音频”；网络慢时无法保证即时出声。缓存仅在内存中保留，刷新即清除，不保存材料或听写。

该缓存通道使用 Microsoft 在线朗读协议，服务变化或网络限制可能导致不可用；此时自动回到同一个已选声音的浏览器朗读，并提示切句可能等待。其他供应商的声音继续使用浏览器朗读。本地 Windows 原生队列未发出开始事件时只尝试一次恢复，不重启已开始的朗读。

| 快捷键 | 功能 |
|---|---|
| Alt+K | 播放、暂停或继续 |
| Alt+J | 上一句并播放 |
| Alt+L | 下一句并播放 |
| Alt+R | 开启／关闭每句三遍模式 |

输入框里也可以使用。切句与重听不清空草稿；重听按钮保留听写框焦点。

## 我们边做边学的第一个小任务

先完成试听，再尝试添加 **0.9 倍速**：打开 `src/lib/workspace.ts`，找到 `RATES` 数组，在 0.75 和 1 之间加上 0.9，保存后查看页面的语速选项。

这一小步用来观察“数组里的数据如何变成下拉框选项”。不需要先掌握整套 React；后面再接着理解按钮事件和状态变化。当前工程代码由助手实现，尚未据此验证用户掌握情况。

## 开发检查

查词区支持单词、短语或整句（最多1000字符）：单词展示词库已有的中文多义释义，并补充变形词的原形释义；不同词条来源会标明原形，不保证每个词都具有多个含义。整句显示“参考译文”，在线免费翻译服务需要网络，可能受额度影响，不会收费或自动开通付费服务。译文供理解语境参考。

桌面查词栏保持在可见区域，词义列表独立滚动，输入框不随结果移走；手机或窄屏可点击右下角“查词 / 译句”随时打开悬浮窗口。查词与翻译不会修改听写内容。

```powershell
npm.cmd test
npm.cmd run build
```

浏览器自动检查脚本是 `scripts/browser-check.js`，仅用于独立 QA 会话。部分检查会模拟声音，不能作为真实音质的验证；专注和临时会话另有相应回归检查。
